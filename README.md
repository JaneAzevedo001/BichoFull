# BichoFull 🐾

Bem-vindo ao **BichoFull**, um simulador do Jogo do Bicho com saldo fictício.  
O objetivo é **aprender a mecânica das apostas** e se divertir sem riscos financeiros.

---

## 🚀 Tecnologias utilizadas
- **Frontend:** React + TypeScript + TailwindCSS
- **Backend:** Node.js + Express
- **Gerenciamento de pacotes:** npm

---

## 📂 Estrutura do projeto
- `src/pages/` → Aplicação React (páginas: Home, Histórico, Autenticação, Apostas)
- `backend/` → API Express (rotas para histórico, apostas, saldo)
- `components/` → Componentes reutilizáveis (botões, cards, tabelas)
- `public/` → Assets estáticos (logo, ícones)
